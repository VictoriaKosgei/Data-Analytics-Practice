# 📊 Data Analytics Practice Projects

Welcome to my **Data Analytics Practice Projects** repository.

This repository contains practical projects demonstrating my developing skills in **data cleaning, exploratory data analysis, SQL querying, data visualization, dashboard development, and business insight generation**.

The projects use different datasets and tools to demonstrate how data can be transformed from raw information into meaningful insights that support data-driven decision-making.

## 📁 Projects

### 1. 🛒 Online Retail Data Cleaning & Exploratory Data Analysis

**Focus:** Data Cleaning, EDA & Business Insights

This project focuses on cleaning and analyzing an Online Retail transactions dataset using Python and Jupyter Notebook.

### Key Activities

- Dataset inspection and profiling
- Missing-value investigation
- Duplicate and invalid-record investigation
- Handling invalid price values
- Investigation of returns and negative quantities
- Revenue calculation
- Product and customer analysis
- Geographic analysis
- Monthly revenue analysis
- Business insight generation
- Data visualization using Matplotlib

### Tools

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

### Key Insights

- November 2011 recorded the highest monthly revenue in the available data.
- REGENCY CAKESTAND 3 TIER generated the highest product revenue.
- WORLD WAR 2 GLIDERS ASSTD DESIGNS had the highest quantity sold.
- The United Kingdom was the dominant market by revenue.
- Missing CustomerID values limited the completeness of customer-level analysis.

📂 **Project:** `Week 1 — Online Retail Data Cleaning & EDA`

### 2. 🎬 Netflix Movies & TV Shows Analysis

**Focus:** Data Cleaning, Exploratory Data Analysis & Dashboard Development

This project analyzes the Netflix Movies and TV Shows dataset to understand the composition and distribution of Netflix's content library.

### Key Activities

- Dataset inspection and profiling
- Missing-value investigation
- Data cleaning and preparation
- Date and release-year analysis
- Movies vs TV Shows analysis
- Genre analysis
- Rating analysis
- Country analysis
- Exploratory data visualization
- Interactive Power BI dashboard development

### Dataset

The final cleaned dataset contains:

- **8,807 rows**
- **12 columns**

### Key Insights

- Movies make up a larger proportion of the Netflix catalog than TV Shows.
- Netflix has a diverse content library covering many genres and categories.
- International content represents a significant part of the catalog.
- Dramas, international movies, and comedies are among the prominent content categories.
- The catalog contains a strong concentration of titles from recent release years.
- Netflix content spans many countries and rating categories.

### Tools

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Power BI
- GitHub

📂 **Project:** `Week 2 — Netflix Movies & TV Shows Analysis`
